# Implementation checklist (planning targets — not yet completed)

## GA1 graphics requirements
- [ ] Own 3D vertex geometry: tiles, pillars, walls, characters
- [ ] Model-view transformations: translation, rotation, scale
- [ ] `lookAt` camera with orthographic tactical / perspective combat projections
- [ ] Keyboard and mouse interaction
- [ ] Animation using `requestAnimationFrame`
- [ ] GLSL lighting and shading with at least one light

## Advanced graphics features
- [ ] Hierarchical modeling: articulated character parts
- [ ] Picking: select tiles / targets with mouse

## Gameplay and networking
- [ ] 10×10 grid and legal movement
- [ ] Two players in LAN lobby / room code
- [ ] Authoritative server validates actions and broadcasts state
- [ ] One movement opportunity and one main action, either order
- [ ] 30-second turn timer
- [ ] HP, stamina, Sword and Staff attacks
- [ ] Basic Defend, Rest and match ending
- [ ] Character stat allocation and elemental choice
- [ ] Elemental abilities: goal all five; backup at least two
- [ ] End-of-match return to lobby

## Submission
- [ ] Confirm team roles, weekly owners, and agreement
- [ ] Commit sketches/storyboard to `docs/`
- [ ] Complete 3–4-page GA1 PDF
- [ ] Check pitch slide maximum (10 slides)
- [ ] Keep AI use log current for GA2 and GA3
