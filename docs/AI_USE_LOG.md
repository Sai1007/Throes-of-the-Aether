## How to add an entry
1. Add a **new row for each meaningful use** of an AI tool (planning, code, debugging, artwork, explanation, writing).
2. Describe the **actual request**, not merely “used ChatGPT.”
3. Note what was **kept, edited, rejected, or verified** by humans.
4. Link the relevant source file, issue, pull request, or commit when available.
5. Never claim that AI-generated code was independently written or tested unless the team actually verified it.
